สี่ด้าน · 01—04
01
Research & Backtest

กรอบทดสอบย้อนหลังที่รันซ้ำได้ผลเดิม

ทุกกลยุทธ์ต้องผ่าน backtest แบบ deterministic — ข้อมูลชุดเดิม พารามิเตอร์ชุดเดิม ต้องได้ผลลัพธ์เดิมทุกครั้ง ไม่มีการสุ่มที่ควบคุมไม่ได้ ทำให้เปรียบเทียบกลยุทธ์และตรวจสอบผลย้อนหลังได้จริง

backtest pipeline● reproducible
Determinismผลลัพธ์คงที่ทุกการรัน
ValidationWalk-forward แบ่งช่วงเวลา
Overfit checkทดสอบนอกกลุ่มตัวอย่าง
Cost modelค่าธรรมเนียม + slippage
  • Walk-forward validation แยก in/out-of-sample
  • คิดค่าธรรมเนียมและ slippage ในโมเดล
  • บันทึกผลทุกรอบไว้เทียบย้อนหลัง
02
Risk Guardrails

ความเสี่ยงถูกบังคับใช้ในโค้ด ไม่ใช่ในวินัย

เพดานขนาดสถานะกำหนดเป็นค่าคงที่ที่ข้ามไม่ได้ การเพิ่มสถานะใช้ขนาดคงที่ ไม่ทบเป็นเท่าตัวแบบ martingale และทุกรอบการตัดสินใจต้องผ่านการตรวจ margin และ delta ก่อนส่งคำสั่ง — ถ้าไม่ผ่าน ระบบไม่ส่ง

risk controls● enforced
Position notional capHard limit · ข้ามไม่ได้
การเพิ่มสถานะขนาดคงที่ · ไม่ทบเท่าตัว
Pre-trade checkMargin & delta ทุกรอบ
Kill switchหยุดระบบได้ทันที
  • ไม่ใช่ martingale — ขนาดไม้คงที่
  • ไม่ผ่านด่านตรวจ = ไม่ส่งคำสั่ง
  • สั่งหยุดฉุกเฉินได้จากแดชบอร์ด
03
Exchange Integration

เชื่อมต่อ exchange พร้อมโหมดจำลองครบวงจร

รองรับการดึงข้อมูลตลาดและส่งคำสั่งผ่าน API ของ exchange พร้อมโหมด dry-run ที่รันตรรกะการตัดสินใจบนข้อมูลจริงโดยไม่ส่งคำสั่งจริง และค่าเริ่มต้นของระบบคือ testnet เสมอ

execution modes● testnet default
Dry-runตรรกะจริง · ไม่ส่งคำสั่ง
Paper / testnetโหมดเริ่มต้นของระบบ
Liveเปิดด้วยธงชัดเจนเท่านั้น
Idempotent ordersกันส่งคำสั่งซ้ำ
  • ทดสอบตรรกะบนข้อมูลตลาดจริงได้ก่อน
  • ขึ้นจริงต้องผ่านช่วง soak ตามรันบุ๊ก
  • กันคำสั่งซ้ำเมื่อการเชื่อมต่อสะดุด
04
Operations & Observability

แดชบอร์ดปฏิบัติการและบันทึกการตัดสินใจ

ทุกระบบมาพร้อมแดชบอร์ดสถานะ บันทึกเหตุผลของทุกการตัดสินใจพร้อม timestamp และการแจ้งเตือนเมื่อระบบเข้าสู่สถานะผิดปกติ — ทำให้ตอบได้เสมอว่าระบบตัดสินใจอะไร เมื่อไร และเพราะอะไร

observability● live
Decision logทุกรอบ พร้อม timestamp
Health statusสถานะระบบเรียลไทม์
Alertingแจ้งเตือนเมื่อผิดปกติ
Access controlแดชบอร์ดต้องมี token
  • ตรวจย้อนหลังได้ว่าตัดสินใจอะไรเพราะอะไร
  • แจ้งเตือนผ่านอีเมลและแชต
  • ปุ่มควบคุมล็อกไว้ด้วย token เสมอ
