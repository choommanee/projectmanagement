Core Capabilities

ฟีเจอร์ที่ออกแบบมาเพื่อการทำงานจริง

ทุกโมดูลเชื่อมต่อกันบนฐานข้อมูลเดียว ข้อมูลไหลตั้งแต่ใบสั่งขายจนถึงสายการผลิตและบัญชี

Project Management

บริหารโครงการแบบ Agile + Waterfall

วางแผน ติดตาม และส่งมอบงานด้วยเครื่องมือที่ทีมจริงใช้ พร้อม Role Workspace เฉพาะทางสำหรับ PM / BA / SA / Expert

  • Backlog, Sprint, Board และ Timesheet ครบวงจร
  • Task hierarchy, worklog และ activity log
  • Workspace แยกตามบทบาท ดึงข้อมูลจากงานจริง
Manufacturing · MRP

วางแผนการผลิตด้วย MRP Engine ประสิทธิภาพสูง

คำนวณความต้องการวัตถุดิบ จัดตารางการผลิต และติดตามใบสั่งผลิตแบบเรียลไทม์ ขับเคลื่อนด้วย compute engine ที่เขียนด้วย Rust

  • BOM, Routing, Work Order และ Lot genealogy
  • MRP net-requirement, Inventory และ Procurement
  • OEE, Work Center, กำลังการผลิต และปฏิทินการผลิต
Quality Management

ควบคุมคุณภาพระดับมาตรฐานอุตสาหกรรม

ครบทั้ง APQP / PPAP, FMEA, Control Plan และวงจร NCR / CAPA เชื่อมโยงตรงกับสายการผลิตและ lot traceability

  • APQP / PPAP workflow และ Control Plan
  • FMEA, Inspection plan และผลตรวจ
  • NCR / CAPA พร้อมการสอบกลับ lot
Workflow Automation

เวิร์กโฟลว์อัตโนมัติแบบ no-code

ออกแบบกระบวนการอนุมัติและงานอัตโนมัติด้วย visual editor รันบน workflow runtime ที่รองรับ expression, switch, HTTP และ human task

  • Visual workflow designer และ template
  • ขั้นตอนอนุมัติ, human task และ HTTP call
  • ติดตามสถานะการรันทุก instance
Reports · BI

แดชบอร์ดและรายงานเชิงวิเคราะห์

สร้างแดชบอร์ดแบบ schema-driven ดึงตัวชี้วัดข้ามโมดูลมาแสดงผลในมุมมองเดียว ช่วยให้ตัดสินใจได้บนข้อมูลจริง

  • Dashboard builder และ widget หลากหลาย
  • ตัวชี้วัดข้ามโมดูล (PM, MFG, Quality, Sales)
  • ออกแบบจาก JSON config ปรับแต่งได้ตามองค์กร
Notifications

แจ้งเตือนหลายช่องทางอัตโนมัติ

ส่งการแจ้งเตือนเข้าระบบ, อีเมล และแชต (Teams / Slack / LINE) ตามเหตุการณ์ พร้อมตั้งค่าช่องทางรายบุคคล

  • In-app, Email และ Chat webhook
  • ตั้งค่าช่องทางต่อผู้ใช้ต่อประเภทเหตุการณ์
  • ขับเคลื่อนด้วย event stream แบบ near real-time
