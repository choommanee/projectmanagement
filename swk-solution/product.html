[ 06 ระบบหลัก ]
01
Project Management

บริหารโครงการแบบ Agile & Waterfall

วางแผน ติดตาม และส่งมอบงานด้วยเครื่องมือที่ทีมใช้จริง พร้อม Workspace เฉพาะบทบาท PM / BA / SA / Expert

  • Backlog · Sprint · Board · Timesheet
  • Task hierarchy & worklog
  • Role workspace จากงานจริง
02
Manufacturing · MRP

วางแผนการผลิตด้วย MRP Engine

คำนวณความต้องการวัตถุดิบ จัดตารางการผลิต และติดตามใบสั่งผลิตแบบเรียลไทม์ ขับเคลื่อนด้วย compute engine ที่เขียนด้วย Rust

  • BOM · Routing · Work Order · Lot
  • MRP · Inventory · Procurement
  • OEE · Work Center · Capacity
03
Quality Management

ควบคุมคุณภาพระดับมาตรฐานอุตสาหกรรม

ครบทั้ง APQP / PPAP, FMEA, Control Plan และวงจร NCR / CAPA เชื่อมโยงตรงกับสายการผลิตและการสอบกลับ lot

  • APQP / PPAP · Control Plan
  • FMEA · Inspection
  • NCR / CAPA · Lot traceability
04
Workflow Automation

เวิร์กโฟลว์อัตโนมัติแบบ no-code

ออกแบบกระบวนการอนุมัติและงานอัตโนมัติด้วย visual editor รันบน runtime ที่รองรับ expression, switch, HTTP และ human task

  • Visual designer · Template
  • Approval · Human task · HTTP
  • ติดตามทุก run instance
05
Reports · BI

แดชบอร์ดและรายงานเชิงวิเคราะห์

สร้างแดชบอร์ดแบบ schema-driven ดึงตัวชี้วัดข้ามโมดูลมาแสดงในมุมมองเดียว ช่วยตัดสินใจบนข้อมูลจริง

  • Dashboard builder
  • ตัวชี้วัดข้ามโมดูล
  • ปรับแต่งจาก JSON config
06
Notifications

แจ้งเตือนหลายช่องทางอัตโนมัติ

ส่งการแจ้งเตือนเข้าระบบ อีเมล และแชต (Teams / Slack / LINE) ตามเหตุการณ์ พร้อมตั้งค่าช่องทางรายบุคคล

  • In-app · Email · Chat webhook
  • ตั้งค่าช่องทางต่อผู้ใช้
  • Event stream near real-time
