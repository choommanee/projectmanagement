01 — ภาพรวม

ระบบทำอะไรได้บ้าง?

PM Platform เป็น ERP แบบ Multi-tenant รองรับหลายบริษัทในระบบเดียวกัน แบ่งออกเป็น 2 โมดูลหลัก

📋
PM Hub — การจัดการโครงการ
โครงการ งาน Sprint Backlog Workflow อัตโนมัติ รายงาน BI และ Workspace สำหรับ BA/SA
🏭
Manufacturing Hub — การผลิต
Work Order BOM Routing MRP คลังสินค้า Lot ตรวจสอบย้อนหลัง ตารางการผลิต และคุณภาพ IATF 16949
ℹ
Multi-tenant: ข้อมูลของแต่ละบริษัทถูกแยกอย่างสมบูรณ์ผ่าน Row-Level Security คุณจะเห็นเฉพาะข้อมูลขององค์กรที่คุณสังกัดเท่านั้น
02 — การเข้าสู่ระบบ

เข้าสู่ระบบ & บทบาท

  1. 01

    เปิดเบราว์เซอร์และไปที่ระบบ

    เปิด URL ที่ผู้ดูแลระบบให้มา ใส่อีเมลและรหัสผ่านที่ได้รับจาก Invite Email

  2. 02

    เลือกองค์กร (Tenant)

    หากบัญชีของคุณสังกัดหลายองค์กร ระบบจะให้คุณเลือกองค์กรก่อนเข้าสู่หน้าหลัก

  3. 03

    เข้าสู่หน้า Dashboard

    ระบบแสดงเมนูและฟีเจอร์ตามบทบาทที่ได้รับ บางเมนูอาจซ่อนอยู่หากบทบาทไม่มีสิทธิ์

บทบาทผู้ใช้งาน

บทบาท สิทธิ์หลัก โมดูลที่เข้าถึงได้
tenant-admin จัดการผู้ใช้งาน ตั้งค่าระบบ สิทธิ์เต็ม ทุกโมดูล
project-manager สร้าง/แก้ไขโครงการ Sprint งาน มอบหมายงาน PM Hub ทั้งหมด
mfg-operator Work Order BOM MRP คลัง Supplier PO Manufacturing Hub
quality-engineer APQP PPAP FMEA NCR CAPA Inspection Quality (MFG Hub)
workflow-author สร้างและแก้ไข Workflow Definition PM Hub → Workflows
bi-author สร้าง Dashboard และ Report PM Hub → Reports
03 — PM Hub

การจัดการโครงการ

สร้างโครงการใหม่

  1. 01

    ไปที่ /pm/projects

    คลิก "Active Projects" ในเมนู Projects ฝั่งซ้าย

  2. 02

    คลิก "+ New Project"

    กรอกชื่อโครงการ วันกำหนดเสร็จ และคำอธิบาย แล้วกด Create

  3. 03

    ตั้งค่าโครงการ

    เพิ่มสมาชิก กำหนด Custom Field และเชื่อมโยง Workflow ที่ต้องการ

งานและ Sprint

แต่ละโครงการสามารถแบ่งงานเป็น Sprint ได้ Sprint มีวันเริ่มและสิ้นสุด และมี Burndown Chart ให้ติดตามความคืบหน้า

Task Backlog
งานที่ยังไม่ได้จัดเข้า Sprint มองเห็นได้ที่ /pm/backlog
Sprint Board
ดู Sprint ปัจจุบันที่ /pm/sprints พร้อม Burndown Chart
My Tasks
งานที่มอบหมายให้คุณดูได้ที่ /pm/tasks

Workflow อัตโนมัติ

Workflow ช่วยกำหนดกระบวนการทำงานอัตโนมัติ เช่น อนุมัติเอกสาร แจ้งเตือนเมื่องานเสร็จ หรือสร้างงานต่อเนื่องโดยอัตโนมัติ

กำหนด Definition → สร้าง Instance → กำหนด Human Task → ผู้ใช้ดำเนินการ → เสร็จสิ้น
✓
เคล็ดลับ: Human Task ที่รอดำเนินการจะแสดงใน /pm/inbox ของผู้ใช้ที่ได้รับมอบหมาย

จัดการผู้ใช้งาน

เฉพาะ tenant-admin เท่านั้นที่เข้าถึง /pm/users ได้

การกระทำวิธีดำเนินการ
เชิญผู้ใช้ใหม่คลิก "Invite User" → กรอกอีเมล ชื่อ รหัสผ่านชั่วคราว และเลือก Roles
แก้ไข Rolesคลิก "Edit roles" ในแถวผู้ใช้ที่ต้องการ
ปิดใช้งานบัญชีคลิก "Deactivate" ในแถวผู้ใช้ บัญชีจะถูกระงับทันที
04 — Manufacturing Hub

การผลิต

รายการสินค้า (Items)

Item คือรายการสินค้าทุกชนิดในระบบ ทั้งวัตถุดิบ ชิ้นส่วน และสินค้าสำเร็จรูป

ประเภท Itemความหมาย
rawวัตถุดิบ — ซื้อมาจากภายนอก
componentชิ้นส่วน — ใช้ประกอบใน BOM
assemblyชุดประกอบ — ผลิตจากหลาย Component
finishedสินค้าสำเร็จรูป — พร้อมขาย
consumableวัสดุสิ้นเปลือง

BOM และ Routing

BOM (Bill of Materials) คือสูตรการผลิต ระบุว่าใช้ชิ้นส่วนอะไร จำนวนเท่าใด
Routing คือลำดับขั้นตอนการผลิต ระบุ Work Center และเวลาที่ใช้ในแต่ละขั้นตอน

  1. 01

    สร้าง BOM สำหรับ Item

    ไปที่ /mfg/bom → เลือก Item → "+ New BOM" → เพิ่ม BOM Lines (ชิ้นส่วนที่ใช้)

  2. 02

    Activate BOM

    BOM ที่สร้างใหม่จะอยู่ในสถานะ Draft กด "Activate" เพื่อเปิดใช้งานกับ Work Order

  3. 03

    สร้าง Routing

    ไปที่ /mfg/routings → เลือก Item → "+ New Routing" → เพิ่ม Operations ตามลำดับ

Work Orders

Work Order คือคำสั่งผลิต ระบุ Item ที่ต้องผลิต จำนวน วันกำหนดส่ง และ Work Center

planned → released → in_progress → completed → closed
⚠
สำคัญ: การ Release Work Order ต้องการสิทธิ์ mfg-operator และระบบจะส่ง Notification ให้ทีมโดยอัตโนมัติ

Lot และการตรวจสอบย้อนหลัง

ระบบรองรับการติดตาม Lot ทุก Lot สามารถดูสายการผลิตย้อนหลัง (Genealogy) และตรวจสอบ Traceability ได้

Genealogy
แสดงชิ้นส่วน (Component Lots) ที่ใช้ในการผลิต Lot นั้น
Traceability
ติดตามว่า Lot นี้ถูกนำไปใช้ที่ไหนบ้าง (Forward) หรือมาจากไหน (Backward)

MRP — การวางแผนความต้องการวัสดุ

MRP Run คำนวณความต้องการวัสดุจาก Sales Order, Work Order และ Forecast เพื่อแนะนำว่าควรสั่งซื้อหรือผลิตอะไรเพิ่ม

  1. 01

    สร้าง MRP Run ใหม่

    ไปที่ /mfg/mrp → "+ New Run" → ตั้งชื่อแล้วกด Run

  2. 02

    ตรวจสอบ Actions

    ระบบแสดง Action แนะนำ เช่น "Release WO", "Reschedule", "Cancel" — ตรวจสอบแล้วดำเนินการตามที่เหมาะสม

ตารางการผลิต (Scheduling Board)

ดูที่ /mfg/scheduling — แสดง Gantt Board แบบ Work Center × วันที่ พร้อม Unscheduled sidebar สำหรับ Work Order ที่ยังไม่ได้กำหนด Work Center

05 — การจัดซื้อ

Supplier และ Purchase Order

ผู้จัดจำหน่าย (Suppliers)

บริหารข้อมูลผู้จัดจำหน่ายที่ /mfg/suppliers รองรับการค้นหา เพิ่ม แก้ไข และปิดใช้งาน

ฟิลด์คำอธิบาย
Codeรหัสผู้จัดจำหน่าย (ต้องไม่ซ้ำในองค์กร)
Nameชื่อบริษัท/ผู้จัดจำหน่าย
Lead Time Daysระยะเวลานำ (วัน) ใช้ในการคำนวณ MRP
Activeปิด/เปิดการใช้งาน — Supplier ที่ปิดไม่สามารถเลือกใน PO ใหม่ได้

ใบสั่งซื้อ (Purchase Orders)

บริหาร PO ที่ /mfg/purchase-orders — หน้าต่างแบ่งซ้าย (รายการ PO) และขวา (รายละเอียด + Line Items)

draft → submitted → approved → partially_received → received
  1. 01

    สร้าง PO ใหม่

    คลิก "+ New PO" → เลือก Supplier → ระบุวันที่คาดว่าจะรับของ → Create

  2. 02

    เพิ่ม Line Items

    ในหน้ารายละเอียด PO → "+ Add Line" → เลือก Item จำนวน และราคาต่อหน่วย

  3. 03

    Submit และติดตามสถานะ

    กด "Submit" เพื่อส่ง PO ให้ Supplier ระบบจะอัปเดตสถานะเมื่อรับสินค้า

คลังสินค้า

ดูยอดคงเหลือและประวัติการเคลื่อนไหวของสต็อกที่ /mfg/inventory

06 — การขาย

ลูกค้าและใบสั่งขาย

ลูกค้า (Customers)

บริหารข้อมูลลูกค้าที่ /pm/customers รองรับการค้นหา เพิ่ม แก้ไข และปิดใช้งาน

✓
เคล็ดลับ: ฟิลด์ Billing Address ใช้สำหรับออกเอกสาร ควรกรอกให้ครบถ้วน

ใบสั่งขาย (Sales Orders)

บริหาร SO ที่ /pm/sales-orders — layout เหมือน PO แบ่งซ้าย-ขวา

draft → confirmed → shipped → invoiced
ℹ
การเชื่อมโยงกับ MRP: SO ที่ Confirmed จะถูกนำไปคำนวณใน MRP Run เพื่อวางแผนการผลิตอัตโนมัติ
07 — คุณภาพ IATF 16949

การควบคุมคุณภาพ

ระบบรองรับมาตรฐาน IATF 16949 ครบชุด

📐
APQP
Advanced Product Quality Planning — วางแผนคุณภาพก่อนเริ่มผลิต
📋
PPAP
Production Part Approval Process — อนุมัติชิ้นส่วนก่อนผลิตจริง
🔍
FMEA
Failure Mode & Effects Analysis — วิเคราะห์ความเสี่ยงกระบวนการผลิต
📊
Control Plan
แผนควบคุมคุณภาพแต่ละจุดในกระบวนการผลิต
⚠️
NCR / CAPA
Non-Conformance Report & Corrective Action — บันทึกและแก้ไขปัญหาคุณภาพ
🔬
Inspections
การตรวจรับสินค้า ตรวจระหว่างผลิต และตรวจก่อนส่ง

NCR และ CAPA

  1. 01

    เปิด NCR

    ไปที่ /mfg/ncrs → "+ New NCR" → ระบุปัญหา ชิ้นส่วนที่เกี่ยวข้อง และความรุนแรง

  2. 02

    กำหนด Root Cause

    วิเคราะห์สาเหตุรากเหง้า (5-Why หรือ Fishbone) และบันทึกลงในระบบ

  3. 03

    CAPA Action Plan

    กำหนดมาตรการแก้ไข ผู้รับผิดชอบ และวันกำหนดเสร็จ ระบบจะส่ง Reminder อัตโนมัติ

08 — รายงานและ Dashboard

BI & Dashboard

ระบบมี Dashboard Builder ให้สร้าง Dashboard แบบ drag-and-drop ได้เอง ไม่ต้องเขียนโค้ด

Reports & BI
รายงานสำเร็จรูป เช่น สถานะ Work Order สต็อกคงเหลือ ยอดขาย /pm/reports
Dashboard Builder
สร้าง Dashboard เองที่ /pm/reports/dashboard เลือก Widget และ Data Source

Audit Log

ทุกการกระทำในระบบถูกบันทึกไว้ใน Audit Log ดูได้ที่ /pm/audit รองรับการกรองตามผู้ใช้ เวลา และประเภทการกระทำ

ℹ
ความปลอดภัย: Audit Log ไม่สามารถแก้ไขหรือลบได้ ข้อมูลถูกเก็บถาวรเพื่อการตรวจสอบ
